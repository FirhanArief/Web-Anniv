Selamat! Web surprise anniversary untuk pasangan Anda telah siap digunakan.

1. CARA MENJALANKAN:
   - Cukup klik dua kali pada file "index.html" untuk membukanya di browser apa saja
     (Google Chrome, Microsoft Edge, Safari, Mozilla Firefox).
   - Bisa juga dibuka melalui HP (cukup bagikan file atau host melalui GitHub Pages / Vercel / Netlify secara gratis).

2. LAGU "VALENTINE" OLEH JIM BRICKMAN:
   - Secara default, web telah dilengkapi pemutar musik yang dapat memutar audio secara langsung.
   - Jika Anda memiliki file MP3 lagu "Valentine - Jim Brickman" di laptop/HP:
     * Opsi A (Langsung dari Web): Buka web, masuk ke bagian "Lagu Kebangsaan Cinta Kita", lalu klik tombol "Ganti MP3" dan pilih file lagunya dari perangkat Anda.
     * Opsi B (Permanen): Masukkan file MP3 Anda ke dalam folder "assets" ini dan beri nama "valentine.mp3". Web akan otomatis membacanya secara offline!

3. FITUR UPLOAD FOTO & VIDEO (INDEXEDDB):
   - Anda atau pasangan Anda dapat langsung mengupload foto (JPG, PNG) atau video kenangan (MP4) langsung dari web.
   - Foto dan video yang di-upload otomatis tersimpan di memori browser perangkat (IndexedDB), sehingga TIDAK AKAN HILANG saat halaman di-refresh!
   - Klik foto/video di galeri untuk melihat dalam ukuran layar penuh (Fullscreen Lightbox).

4. HITUNG MUNDUR (COUNTDOWN):
   - Timer hitung mundur secara otomatis menghitung waktu menuju tanggal sakral 16 Desember 2026 (Anniversary ke-7).

Semoga momen kejutan anniversary ini menjadi kenangan terindah dan membahagiakan untuk Anda dan pasangan tercinta! ❤️💙
