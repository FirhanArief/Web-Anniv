PANDUAN WEB SURPRISE ANNIVERSARY KE-7 (16 DESEMBER 2026)
Tema: Merah (Cinta) & Biru (Keceriaan)
========================================================================

Selamat! Web surprise anniversary untuk pasangan Anda telah siap digunakan.

1. CARA MENJALANKAN:
   - Cukup klik dua kali pada file "index.html" untuk membukanya di browser apa saja
     (Google Chrome, Microsoft Edge, Safari, Mozilla Firefox).
   - Bisa juga dibuka melalui HP (cukup bagikan file atau host melalui GitHub Pages / Vercel / Netlify secara gratis).

2. LAGU "VALENTINE" OLEH JIM BRICKMAN:
   - Secara default, web telah dilengkapi pemutar musik yang dapat memutar audio secara langsung.
   - Jika Anda memiliki file MP3 lagu "Valentine - Jim Brickman" di laptop/HP:
     * Opsi A (Langsung dari Web): Buka web, masuk ke bagian "Lagu Kebangsaan Cinta Kita", lalu klik tombol "Ganti MP3" dan pilih file lagunya dari perangkat Anda.
     * Opsi B (Permanen): Masukkan file MP3 Anda ke dalam folder "assets" ini dan beri nama "valentine.mp3". Web akan otomatis membacanya secara offline!

3. ALBUM GALERI POLAROID & FITUR UPLOAD PERMANEN:
   - Koleksi 24 Foto Kenangan Utama (Maret 2025 s/d Oktober 2026) ditampilkan rapi dalam desain kartu Polaroid Modern lengkap dengan efek washi-tape dan stempel tanggal.
   - FITUR UPLOAD FOTO BARU (OTOMATIS TERSIMPAN & BISA DILIHAT):
     * Tombol "Upload Foto ke Album": Klik tombol di toolbar atas galeri atau tarik (drag-and-drop) foto langsung ke area galeri.
     * Multi-Upload (Banyak Foto Sekaligus): Anda dapat memilih beberapa foto sekaligus, sistem akan otomatis mengompresi dan menyimpannya secara berurutan ke album.
     * Dukungan Kamera Langsung: Klik tombol "Kamera" untuk mengambil foto langsung dari HP/laptop.
     * Penyimpanan Permanen Otomatis: Foto yang diunggah disimpan di IndexedDB browser (dengan cadangan LocalStorage). Saat web direfresh atau dibuka kembali, foto tetap tersimpan dan langsung terlihat di album ("Foto Unggahan Kita").
     * Fullscreen Lightbox Album: Klik foto apa saja untuk membuka resolusi penuh dengan navigasi panah, swipe di HP, dan tombol hapus/jadikan sorotan utama.
     * Jadikan Sorotan Utama (Bintang): Klik ikon bintang pada kartu foto apa saja untuk menjadikannya foto polaroid utama di bagian paling atas (Hero Section).
     * Backup & Impor Cadangan: Tersedia tombol "Backup Album" untuk mengunduh semua foto unggahan Anda ke dalam file .json, dan tombol "Impor Cadangan" untuk memulihkannya kembali kapan saja di browser lain!

4. HITUNG MUNDUR (COUNTDOWN):
   - Timer hitung mundur secara otomatis menghitung waktu menuju tanggal sakral 16 Desember 2026 (Anniversary ke-7).

Semoga momen kejutan anniversary ini menjadi kenangan terindah dan membahagiakan untuk Anda dan pasangan tercinta! ❤️💙
